# Canada Immigration Trends Analysis (1980–2013)

## Project Overview
This project explores immigration trends to Canada from 1980 to 2013 using Python. The objective is to understand how immigration patterns changed over time, identify the countries contributing the highest number of immigrants, and explore differences across countries.

## Business Objectives
- Analyze historical immigration trends to Canada.
- Identify the top five countries by total immigration.
- Compare immigration patterns across selected countries.
- Explore the distribution and variation of immigration numbers.
- Identify potential outliers in immigration data.

## Tools & Technologies
- Python
- Google Colab / Jupyter Notebook
- Pandas – data manipulation and analysis
- NumPy – numerical operations
- Matplotlib – data visualization

## Analysis & Methodology
1. Data loading and initial exploration.
2. Data inspection and preparation.
3. Analysis of immigration trends by country and year.
4. Identification of the top five countries by total immigration.
5. Comparative analysis of selected countries.
6. Statistical exploration using quartiles and the Interquartile Range (IQR).
7. Data visualization to communicate findings.

## Visualizations
- Line charts – immigration trends over time.
- Horizontal bar charts – comparison of top immigration countries.
- Box plots – distribution and potential outlier identification.
- Scatter plots – exploration of relationships between variables.
